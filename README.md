# 歌词随身听

面向手机的中文音乐网页播放器，使用原生 HTML、CSS 和 JavaScript，无需安装依赖或编译。

## 功能

- 赵雷 31 首现场录音及配套同步 LRC 歌词。
- 李志 78 首歌曲，音频保存在本仓库，暂未配套同步歌词。
- 赵雷、李志、全部三个曲库分类，以及独立播放队列。
- 顺序播放、单曲循环、随机播放，上一首、下一首、拖动进度。
- 封面页与完整歌词页切换，歌词多选及本地生成分享图片。
- 支持的浏览器可生成静音 MP4 分享视频。
- 网页安装信息、页面缓存和系统媒体控制。

## 部署到 GitHub Pages

1. 将本目录内容提交到 GitHub 仓库的 `main` 分支。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
3. 在 **Actions** 中运行 **Deploy player to GitHub Pages**，或推送一次网页修改。
4. 等待部署成功后，通过 **Settings → Pages** 或部署任务返回的地址访问。

赵雷 31 首与李志 78 首音频均已导入本仓库，并逐个比对 SHA-256。部署和播放不依赖原作者仓库或原播放器网站。工作流先运行现有播放和分享检查，然后只发布 `dist/`。播放器使用相对资源路径，可部署在仓库子路径下。代码也可放到其他静态网站服务，无需服务端。

## 本地运行

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

在浏览器打开 `http://127.0.0.1:4173/`。页面不会主动播放声音。

检查需要 Node.js 20 或更高版本，无需第三方依赖：

```sh
node tests/playback.cjs
node tests/share-video.cjs
```

## 文件结构

- `dist/`：网页源码和发布资源，包括全部 109 首音频与赵雷歌词。这里不是可随意删除的构建缓存。
- `dist/apple-ui.css`：参考 Apple Liquid Glass 的材质、系统字体、浅色／深色外观与响应式布局。
- `dist/appearance.js`：进度条填色和系统主题色；不负责播放控制。
- `dist/app.js`：曲库、下载、播放、队列、进度和歌词同步。
- `dist/catalog-lizhi.js`：李志曲目清单，使用本站文件及本仓库 Raw 备用地址。
- `dist/share-card.js`、`dist/lyric-share.js`、`dist/share-video.js`：本地图片和视频分享。
- `dist/sw.js`：页面与歌词缓存；不主动缓存音频。
- `tests/`：现有的 77 项播放/分享检查和 15 项视频检查。
- `.github/workflows/pages.yml`：GitHub Pages 部署流程。

## 维护约定

保留原生实现、现有曲库和用户操作方式。切换分类仅浏览；点击歌曲才改变播放队列。歌词分享使用歌曲快照，不干扰播放。

界面默认跟随系统浅色／深色外观，并支持减少动态效果、减少透明度和提高对比度。玻璃材质主要用于导航和控制层，歌词与封面保持内容层的清晰度。窄屏下曲库仍从右上角打开，歌词分享仍为全屏选择页。网页版使用 CSS 实现相近的材质与层级，并非 Apple 原生渲染组件。

修改公开资源后更新 `dist/sw.js` 的缓存名称；修改脚本时同步检查 HTML 和缓存清单中的版本参数。增删曲目时同步检查音频、歌词、曲库清单和 Service Worker 的歌词列表。

播放器按需下载当前歌曲，开始播放后仅预载队列下一首。保留请求取消、播放意图和旧请求隔离逻辑，避免暂停后自动播放或快速切歌时串歌。

李志音频最初来自 [lvboda/lizhi-mp3](https://github.com/lvboda/lizhi-mp3) 固定提交 `2128926ed32e26b7ef6610246175a4fe5992b7c0`。现在 78 首原文件已完整保存在 `dist/audio/lizhi/001.mp3` 至 `078.mp3`；优先读取本站文件，失败后读取本仓库的 GitHub Raw 地址，两条路径均由本账号控制。文件字节未重新编码，来源路径、Git blob 和 SHA-256 见 `sources/lizhi.json`。网页运行时不再请求原作者的仓库或 CDN。

分享图片和视频在设备本地生成。微信状态可先保存图片，再从相册选择；直接系统分享受设备与应用兼容性影响。自动化检查不替代手机锁屏播放或系统分享的真机验证。

本包用于迁移现有播放器，不附带对音频、歌词或封面内容的额外授权。
